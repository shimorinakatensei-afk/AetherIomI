# Security Policy

## Supported version

Security reports should refer to the latest version on the repository's default branch.

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue. Contact the project owner privately through a verified contact method published in the repository owner's GitHub profile or organization page.

Do not include private study records, account credentials, or other personal information in a report.

## Scope notes

Aether currently runs as a static client-side application and stores study data in browser `localStorage`. It does not provide user accounts or a project-owned server. Third-party frontend assets are loaded from public CDNs; see [PRIVACY.md](PRIVACY.md).
