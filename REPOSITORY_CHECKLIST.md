# Public repository checklist

Before making the repository public:

- [ ] Confirm the project name and attribution: **Aether by IOMI Roman & Co.**
- [ ] Choose a software license, or deliberately keep the repository unlicensed.
- [ ] Review every committed file for credentials, private information, or unrelated content.
- [ ] Test the application in current desktop and mobile browsers.
- [ ] Verify the GitHub Pages deployment.
- [ ] Decide whether CDN dependencies should be pinned or bundled for a production release.
- [ ] Consider adding a screenshot to the README after capturing the real running application.
- [ ] Review `PRIVACY.md` whenever storage or network behavior changes.
